# Myles — Portfolio

Personal portfolio site. Single self-contained HTML page.

**Live site:** https://mylesrossi-GH.github.io/myles-portfolio/

## Editing

Everything lives in `index.html` — HTML, CSS and JS are all in that one file.
Open it in a browser to preview changes locally.

To publish changes:

```
git add -A
git commit -m "describe what you changed"
git push
```

GitHub Pages redeploys automatically, usually within a minute.
